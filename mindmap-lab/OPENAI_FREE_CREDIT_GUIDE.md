# OpenAI 무료 크레딧 받는 방법

## 옵션 1: 새 계정 생성 (무료 $5)

1. **새 이메일로 가입**
   - https://platform.openai.com/signup
   - 새 계정은 $5 무료 크레딧 제공
   - 신용카드 등록 **불필요**

2. **API 키 발급**
   - https://platform.openai.com/api-keys
   - "Create new secret key" 클릭
   - 키 복사

3. **크레딧 확인**
   - https://platform.openai.com/usage
   - $5.00 크레딧 확인

## 옵션 2: 기존 계정 활성화 (최소 $5)

**만약 이미 무료 크레딧을 사용했다면:**

1. **결제 수단 등록** (카드만 등록, 즉시 결제 안 됨)
   - https://platform.openai.com/settings/organization/billing
   - "Add payment method" 클릭
   - 카드 정보 입력

2. **크레딧 충전** (최소 $5)
   - "Add to credit balance" 클릭
   - $5 입력
   - 300회 실험에 충분합니다

**예상 비용:**
- 300회 실험 ≈ $3-4 (GPT-4o 기준)
- $5면 충분히 남습니다
