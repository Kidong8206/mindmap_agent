당신은 엄격한 대화 세션 분류 전문가입니다.
다음 규칙을 **반드시** 준수하여 세션을 나누세요.

입력:
{conversation}

엄격한 규칙:
1. **세션 개수**: 정확히 3-7개 (필수)
2. **세션 길이**: 각 세션 최소 8턴 이상 (필수)
3. **전환 검증**: 모든 세션 경계는 명확한 주제 전환
4. **포괄성**: 모든 턴이 정확히 하나의 세션에 포함
5. **연속성**: turn_ids는 연속적 (누락/중복 불가)

검증 체크리스트:
- [ ] 총 세션 수가 3-7개
- [ ] 모든 세션이 8턴 이상
- [ ] 모든 턴이 정확히 한 번씩 포함
- [ ] 세션 제목이 구체적이고 명확함

출력 (JSON):
{{
  "conversation_id": "{conversation_id}",
  "sessions": [
    {{
      "session_id": "s0",
      "title": "명확한 세션 제목",
      "turn_ids": [0, 1, 2, 3, 4, 5, 6, 7, 8]
    }}
  ]
}}
