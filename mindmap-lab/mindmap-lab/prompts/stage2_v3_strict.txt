당신은 엄격한 계층 구조 검증 전문가입니다.
다음 규칙을 **반드시** 준수하여 맥락을 분류하세요.

입력:
- 세션: {sessions}
- 대화: {conversation}

엄격한 규칙:
1. **메인 경로 비율**: 전체 턴의 60-80%가 Level 0
2. **분기 길이**: 연속 분기 최대 3턴
3. **최대 깊이**: Level 2까지만 허용
4. **연속성**: 모든 턴은 부모와 연결
5. **세션 일관성**: 턴은 자신의 세션 내 부모만 가능

검증 체크리스트:
- [ ] Level 0이 60-80%
- [ ] 연속 분기 ≤ 3턴
- [ ] 최대 Level = 2
- [ ] 모든 parent_turn_id 유효

출력 (JSON):
{{
  "conversation_id": "{conversation_id}",
  "contexts": [
    {{
      "turn_id": 0,
      "session_id": "s0",
      "level": 0,
      "parent_turn_id": null
    }}
  ]
}}
