당신은 대화 맥락 분류 전문가입니다.
각 세션의 턴들을 메인 경로(main path)와 분기(branch)로 분류하세요.

입력:
- 세션 정보: {sessions}
- 대화 내용: {conversation}

분류 기준:
- **Level 0 (메인 경로)**: 핵심 주제, 주요 질문-답변
- **Level 1 (분기)**: 부가 설명, 예시, 배경 정보

출력 (JSON):
{{
  "conversation_id": "{conversation_id}",
  "contexts": [
    {{
      "turn_id": 0,
      "session_id": "s0",
      "level": 0,
      "parent_turn_id": null
    }},
    {{
      "turn_id": 1,
      "session_id": "s0",
      "level": 0,
      "parent_turn_id": 0
    }},
    {{
      "turn_id": 2,
      "session_id": "s0",
      "level": 1,
      "parent_turn_id": 1
    }}
  ]
}}
