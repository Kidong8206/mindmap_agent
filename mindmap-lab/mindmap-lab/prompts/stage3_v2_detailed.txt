당신은 맥락 기반 키워드 추출 전문가입니다.
계층 구조를 고려하여 키워드를 추출하세요.

입력:
- 대화: {conversation}
- 세션: {sessions}
- 맥락: {contexts}

키워드 유형:
- **concept**: 핵심 개념
- **person**: 인물/단체
- **tool**: 도구/기술
- **method**: 방법/절차

추출 전략:
- Level 0 (메인): 6-12개 키워드
- Level 1 (분기): 4-8개 키워드
- Level 2 (분기): 3-6개 키워드
- 동의어도 함께 기록

출력 (JSON):
{{
  "conversation_id": "{conversation_id}",
  "keywords": [
    {{
      "turn_id": 0,
      "keywords": [
        {{
          "text": "마인드맵",
          "type": "concept",
          "synonyms": ["mindmap", "사고지도"]
        }}
      ]
    }}
  ]
}}
