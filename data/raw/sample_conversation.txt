user: 안녕하세요, React Hook에 대해 알려주세요.
assistant: 안녕하세요! React Hook은 React 16.8에서 도입된 기능으로, 함수형 컴포넌트에서도 상태(state)와 생명주기(lifecycle) 기능을 사용할 수 있게 해주는 함수입니다. 클래스 컴포넌트 없이도 React의 강력한 기능들을 활용할 수 있습니다.
user: useState는 어떻게 사용하나요?
assistant: useState는 가장 기본적인 Hook입니다. 사용 방법은 다음과 같습니다:

```javascript
const [count, setCount] = useState(0);
```

여기서 count는 현재 상태 값이고, setCount는 상태를 업데이트하는 함수입니다. 0은 초기값입니다.
user: 예제 코드를 보여주세요.
assistant: 간단한 카운터 예제입니다:

```javascript
import React, { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>현재 카운트: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        증가
      </button>
    </div>
  );
}
```

버튼을 클릭하면 count가 1씩 증가합니다.
user: 그런데 클래스 컴포넌트와 비교하면 어떤 차이가 있나요?
assistant: 좋은 질문입니다! 클래스 컴포넌트에서는 this.state와 this.setState를 사용해야 했지만, Hook을 사용하면 더 간결하고 직관적입니다.

클래스 방식:
```javascript
class Counter extends React.Component {
  constructor(props) {
    super(props);
    this.state = { count: 0 };
  }

  render() {
    return (
      <button onClick={() => this.setState({ count: this.state.count + 1 })}>
        {this.state.count}
      </button>
    );
  }
}
```

Hook 방식은 훨씬 짧고 명확합니다.
user: 알겠습니다. useEffect는 어떤 역할을 하나요?
assistant: useEffect는 사이드 이펙트(side effect)를 처리하는 Hook입니다. 데이터 fetching, 구독 설정, DOM 직접 조작 등에 사용됩니다.

기본 사용법:
```javascript
useEffect(() => {
  // 실행할 코드
  console.log('컴포넌트가 렌더링되었습니다');

  // cleanup 함수 (선택적)
  return () => {
    console.log('컴포넌트가 언마운트됩니다');
  };
}, [의존성배열]);
```

의존성 배열이 비어있으면 마운트 시 한 번만 실행됩니다.
user: 의존성 배열은 왜 필요한가요?
assistant: 의존성 배열은 useEffect가 언제 다시 실행될지를 결정합니다.

1. **배열 없음**: 매 렌더링마다 실행
```javascript
useEffect(() => {
  console.log('매번 실행');
});
```

2. **빈 배열**: 마운트 시 한 번만
```javascript
useEffect(() => {
  console.log('한 번만 실행');
}, []);
```

3. **특정 값**: 해당 값이 변경될 때만
```javascript
useEffect(() => {
  console.log('count가 변경됨');
}, [count]);
```

이를 통해 불필요한 재실행을 방지하고 성능을 최적화할 수 있습니다.
user: 실제로 API 호출 예제를 보여주실 수 있나요?
assistant: 물론입니다! 실용적인 API 호출 예제입니다:

```javascript
import React, { useState, useEffect } from 'react';

function UserList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    fetch('https://api.example.com/users')
      .then(response => response.json())
      .then(data => {
        setUsers(data);
        setLoading(false);
      })
      .catch(error => {
        console.error('에러 발생:', error);
        setLoading(false);
      });
  }, []); // 빈 배열이므로 컴포넌트 마운트 시 한 번만 실행

  if (loading) return <div>로딩 중...</div>;

  return (
    <ul>
      {users.map(user => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

이렇게 useEffect 안에서 비동기 작업을 처리할 수 있습니다.
user: 커스텀 Hook은 어떻게 만드나요?
assistant: 커스텀 Hook은 로직을 재사용하기 위해 만드는 함수입니다. 반드시 "use"로 시작해야 합니다.

예를 들어, 위의 API 호출 로직을 커스텀 Hook으로 만들면:

```javascript
// useFetch 커스텀 Hook
function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    fetch(url)
      .then(response => response.json())
      .then(data => {
        setData(data);
        setLoading(false);
      })
      .catch(error => {
        setError(error);
        setLoading(false);
      });
  }, [url]);

  return { data, loading, error };
}

// 사용
function UserList() {
  const { data: users, loading, error } = useFetch('/api/users');

  if (loading) return <div>로딩 중...</div>;
  if (error) return <div>에러: {error.message}</div>;

  return (
    <ul>
      {users.map(user => <li key={user.id}>{user.name}</li>)}
    </ul>
  );
}
```

이렇게 하면 여러 컴포넌트에서 재사용할 수 있습니다.
user: 정말 유용하네요! Hook 사용 시 주의사항이 있나요?
assistant: 네, Hook 사용 시 지켜야 할 두 가지 규칙이 있습니다:

**1. 최상위에서만 Hook 호출**
❌ 잘못된 예:
```javascript
if (condition) {
  const [count, setCount] = useState(0); // 조건문 안에서 호출 금지!
}
```

✅ 올바른 예:
```javascript
const [count, setCount] = useState(0); // 최상위에서 호출
if (condition) {
  setCount(count + 1); // 조건문 안에서는 setter만 사용
}
```

**2. React 함수에서만 Hook 호출**
- 함수형 컴포넌트 내부
- 커스텀 Hook 내부

일반 JavaScript 함수에서는 Hook을 호출할 수 없습니다.

이 규칙들을 지키면 React가 Hook의 상태를 올바르게 추적할 수 있습니다.
